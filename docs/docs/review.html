TICGIT DOCS CODE REVIEW

Code Review

Commands: ti review, ti state review, ti code

TicGit reviews are lightweight signoffs attached to tickets. A review ties together a branch, a set of reviewers, and their verdicts — all stored as git-meta metadata that syncs with the repo.

Walkthrough: three-person review

Alice finishes work on a feature branch. She links it to her ticket, requests review from Bob and Carol, and marks it ready.

1. Author sets up the review

ALICE
# Link the branch to the ticket
$ ti code https://github.com/team/repo:feature-auth -t a3f
 
# Request reviewers
$ ti review request bob@example.com -t a3f
Requested review from bob@example.com on a3f29c.
 
$ ti review request carol@example.com -t a3f
Requested review from carol@example.com on a3f29c.
 
# Mark the ticket as ready for review
$ ti state review -t a3f
 
# Push the ticket metadata so reviewers can see it
$ ti sync

2. Reviewers pull and respond

BOB
# Pull latest ticket data
$ ti sync
 
# See what needs review
$ ti list --state review
  a3f29c 2d Add auth tokens open review alice feature
 
# Check the ticket and its branch
$ ti show a3f
  Code : https://github.com/team/repo:feature-auth
  Reviewers: bob@example.com, carol@example.com
  Reviews : (none yet)
 
# Approve
$ ti review approve -t a3f
bob@example.com approved a3f29c.
 
$ ti sync
CAROL
$ ti sync
 
# Request changes with a reason
$ ti review reject -t a3f "Token expiry should be configurable, not hardcoded to 24h"
carol@example.com requested changes on a3f29c.
 
$ ti sync

3. Author addresses feedback and re-requests

ALICE
$ ti sync
 
# See review status
$ ti show a3f
  Reviews:
    bob@example.com approved 2026-05-10
    carol@example.com rejected 2026-05-10
      "Token expiry should be configurable, not hardcoded to 24h"
 
# Fix the code, push, then re-request Carol
$ ti review request carol@example.com -t a3f
$ ti comment -t a3f "Made token expiry configurable via env var"
$ ti sync

4. Final approval and merge

CAROL
$ ti sync
$ ti review approve -t a3f "Looks good now"
carol@example.com approved a3f29c.
$ ti sync
ALICE
$ ti sync
 
# All reviewers approved — merge the branch and close
$ git merge feature-auth
$ ti close a3f
$ ti sync

Command reference

Request a reviewer

REQUEST
$ ti review request alice@example.com
$ ti review request alice@example.com bob@example.com
 
# Remove a reviewer
$ ti review unrequest alice@example.com

Submit a verdict

VERDICTS
$ ti review approve
$ ti review approve "LGTM"
 
$ ti review reject "Needs error handling on line 42"
 
$ ti review comment "Have you considered using an enum here?"

Verdicts: approve, reject, comment. A new verdict from the same reviewer replaces their previous one.

Check review status

STATUS
$ ti review -t a3f
  a3f29c Add auth tokens
  Branch: https://github.com/team/repo:feature-auth
  Reviewers:
    bob@example.com approved
    carol@example.com approved "Looks good now"
  Status: all approved

Find tickets needing review

FILTER
$ ti list --state review
 
# Tickets where you are a requested reviewer
$ ti list --reviewer bob@example.com
